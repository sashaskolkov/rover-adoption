# Ровер — прототип «усынови робота»

Кликабельный прототип-тизер для партнёров. Идея: как в приложениях по «адопшену»
акул и китов, пользователь получает себе ровера — видит его на карте, зовёт по имени,
переодевает и слушает подкаст, который ведёт команда роверов.

Прототип открывается по ссылке в любом браузере: на десктопе — в макете айфона,
на телефоне — во весь экран. Можно добавить на домашний экран как приложение (PWA).

## Что можно потрогать

| Экран | Что работает |
|---|---|
| **Карта** | Семён и семеро чужих роверов — Пика Пика, Кипелов, R2D2, Бублик, Шуруп, Валера, Зефирка — едут по настоящим тротуарам Хамовников со скоростью пешехода, 4,4–6,0 км/ч. Тап по маркеру переключает на ровера, тап по плашке сверху возвращает к своему. |
| **Карточка ровера** | Шторка в две позиции. Серийный номер, текущая скорость, расстояние до вас (пересчитывается раз в секунду, меняется по метру), заряд, статистика, список роверов рядом с живыми дистанциями. |
| **«Как дела?»** | Ровер отвечает статусом — «Очень много работы. За последние сутки отвёз 37 заказов…» |
| **«Сигнал»** | Маркер мигает, идёт звуковой «бип», на телефоне — вибрация. |
| **«Кадр дня»** | Фото «из глаз ровера» — один раз в сутки, потом таймер до следующего. Шесть сцен. |
| **Пуш** | Прилетает сам, когда Семён подъезжает ближе 260 м. Вручную — колокольчик на карте или Профиль → Демо. |
| **Гардероб** | 10 скинов за виртуальные болты ⚙️. Покупка, примерка, надевание. Скин сразу виден на карте и у других. |
| **Подкаст** | «Восемь колёс» — 7 выпусков, свежий про поход роверов к психотерапевту. Плеер с прогрессом, перемотка ускорена для демо. |
| **Профиль** | Уровень, достижения, дневник ровера и демо-кнопки для показа. |

Прогресс хранится в `localStorage`. Сброс — Профиль → Демо-режим → «Сбросить весь прогресс».

## Демо-кнопки для показа партнёрам

Профиль → Демо-режим:
- прислать пуш «ровер рядом»
- сбросить кадр дня
- начислить 1 000 ⚙️ (чтобы показать покупку дорогого скина)
- сбросить весь прогресс

## Как устроено

Статика без сборки — открывается как есть.

```
index.html              разметка всех экранов
css/styles.css          стили
js/art.js               ровер и скины рисуются в SVG на лету + сцены «кадра дня»
js/data.js              контент: роверы, скины, выпуски, статусы
js/routes.js            геометрия маршрутов, выгружена из OpenStreetMap
js/app.js               логика, карта, движение, состояние
tools/make-icons.js     генерация PNG-иконок приложения
tools/fetch-routes.js   перевыгрузка маршрутов из OSM
```

Карта — [Leaflet](https://leafletjs.com) на тайлах OpenStreetMap, приглушённых
CSS-фильтром под светлый городской стиль. Роверы — не картинки, а параметрический SVG:
скин меняет цвета корпуса, крышки, глаз и добавляет аксессуар, поэтому новый скин — это
десять строк в `js/data.js` и один `case` в `js/art.js`.

**Движение.** Маршруты в `js/routes.js` — не нарисованные от руки петли, а реальная
геометрия тротуаров и дорожек, выгруженная пешеходным роутером OpenStreetMap. Ровер
идёт по полилинии в метрах, а не в градусах, поэтому скорость честно равна заявленной
в `kmh` и не зависит от длины сегмента. Заряд садится линейно, примерно 1% за три
минуты — за демо он заметно ползёт вниз, но никогда не дёргается.

Перевыгрузить маршруты (например, если менять район или добавлять роверов):

```bash
node tools/fetch-routes.js
```

Скрипт ходит в сеть только в этот момент; сам прототип остаётся статикой.

## Локальный запуск

```bash
python3 -m http.server 4321
```

Потом открыть http://localhost:4321

## Оговорки

Прототип, а не продукт. Роверы вымышленные, статусы и статистика — тоже.
Звук и вибрация работают только после первого касания экрана (ограничение браузеров).
Дизайн опирается на публичные изображения роверов Яндекса и не является финальным.
